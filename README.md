 Guess The Number — C++ Console Game

A simple yet engaging number guessing game built in C++.
Test your luck and logic to find the secret number between 1 and 100!
You have 10 chances — can you guess it before time runs out?

 Features:

Random number generation between 1–100

Input validation (prevents invalid or out-of-range guesses)

Dynamic scoring system (lose 10 points per wrong guess)

“Getting close” hints for near guesses

Replay option and ASCII-based win/lose screens

Clean and colorful console UI (using iomanip, conio.h, chrono)

 How to Play:

Run the program.

Guess the secret number between 1–100.

Each wrong guess reduces your score by 10.

Win by guessing the correct number before running out of 10 chances!

 Tech Stack:

Language: C++

Libraries: <iostream>, <ctime>, <iomanip>, <conio.h>, <chrono>, <thread>, <cstdlib>
